# CONTEXT

Viewer for Wayfinder maps that live on the visitor’s disk.

## Glossary

- **Reader** — This product: shows Wayfinder maps from a chosen **Project**. Two versions: the hosted origin (static HTML/JS at a public HTTPS URL, Load via a **Directory handle** or a **Directory snapshot**) and **Always-on** (Hono at `127.0.0.1:5420`, Load via a **Project path**, **Archive**). One page for both. The sidebar is the **Map list**; the pane is GFM preview with **Term hints**, or a **Paste preview**. The hosted Reader does not edit, claim, resolve, or Archive. It never writes the Project. Safari is not a hosted browser. Locked in [ADR 0011](docs/adr/0011-static-public-origin-for-the-reader.md), [ADR 0012](docs/adr/0012-file-system-access-load.md), [ADR 0013](docs/adr/0013-hosted-reader-does-not-archive.md), [ADR 0014](docs/adr/0014-always-on-stays-a-version.md), [ADR 0015](docs/adr/0015-always-on-hono-path-load-and-archive.md), and [ADR 0018](docs/adr/0018-hosted-directory-snapshot-fallback.md).
- **Project** — A folder on the filesystem the user selects. One repo, not a parent of several products. It may contain one or more **Sites**.
- **Directory handle** — Load identity on the hosted origin when the browser can grant standing permission on a chosen **Project** folder. Hosted recents use this. Re-prompt on restore is expected. **Always-on** does not Load this way.
  _Avoid_: Project path, Directory snapshot (when you mean handle Load or hosted recents)
- **Directory snapshot** — Load identity on the hosted origin when the browser cannot grant a **Directory handle**: a one-shot folder pick held in the session. Not recents. Not a standing permission. Not a **Project path**. Safari is out: that pick can omit `.scratch`. Locked in [ADR 0018](docs/adr/0018-hosted-directory-snapshot-fallback.md).
  _Avoid_: Directory handle, Project path, FileList, webkitdirectory (when you mean this identity)
- **Project path** — Load identity on **Always-on**: the absolute POSIX path typed or pasted and stored on the server (`~/.wayfinder-reader/state.json`, last path + recents). Not Load on the hosted origin.
- **Site** — A directory inside the **Project** that owns `CONTEXT.md` and/or `.scratch/`. The Project root is a Site when it has either marker. `CONTEXT.md` inside an **Effort** is not a Site. A Site may have language, a tracker, or both.
  _Avoid_: folder, package, nested project, bare repository (when you mean this unit)
- **Site lineage** — The chain of **Sites** that contain a previewed path, closest owner first, Project root last. Containment is directory membership, walk up only. Siblings, cousins, and descendants are out. Identity is the Site’s path in the Project, not display title.
  _Avoid_: Site tree, ancestor list, context chain (when you mean this chain)
- **Context map** — Optional Project-root `CONTEXT-MAP.md`. It may title and order listed **Sites**. It is not an allowlist: an unlisted Site still appears from its markers. Locked in [ADR 0010](docs/adr/0010-marker-walk-finds-sites.md).
  _Avoid_: Map (that is an Effort index)
- **Effort** — A work directory directly under a **Site**’s `.scratch/` that has a **Map**, a **Spec**, **Tickets**, or any combination. Two Sites may share a slug; identity is the path in the Project.
  _Avoid_: folder (when you mean this unit)
- **Map** — The index issue for an Effort (`map.md` locally): Destination, Notes, Decisions so far, fog, out of scope. It lists decisions; it does not restated their detail. Optional; an Effort can be Spec-only or Ticket-only.
- **Ticket** — A child issue in an Effort (`issues/NN-*.md`). One decision, investigation, prototype, unblocker task, or implementation slice. Not required to sit under a Map.
- **Spec** — The buildable plan `/to-spec` publishes as `spec.md` in an Effort. `Status: ready-for-agent` means fully specified and grabable (`/implement` or `/to-tickets`), not Finished. An Effort with a Spec and no Map is Spec-only: that is remaining work.
- **Finished** — An Effort with at least one **Ticket**, every Ticket resolved (`Status: resolved` or `Status: done`, those two strings only). Spec, research, prototypes, and fog do not vote. `map.md` is not required. Spec-only with zero Tickets is not Finished. Locked in [ADR 0017](docs/adr/0017-done-is-a-read-alias-of-resolved.md).
- **Archive** — `.scratch/.archive/<slug>/`. Hidden; the Map list skips it. A **Finished** Effort moves here. Not a hard delete. The hosted **Reader** does not Archive; **Always-on** does (Hono `fs.rename`). No Archive list and no Restore. Locked in [ADR 0007](docs/adr/0007-archive-finished-efforts.md), amended by [ADR 0013](docs/adr/0013-hosted-reader-does-not-archive.md) and [ADR 0015](docs/adr/0015-always-on-hono-path-load-and-archive.md).
- **Unresolved filter** — A **Map list** mode that hides resolved Tickets and **Finished** Efforts. Default on; session only (not stored with the **Directory handle**, **Directory snapshot**, or **Project path**). Language documents, **ADRs**, and **Out-of-scope records** stay. Open Tickets (including claimed and blocked) stay. A control shows the full live list. Archived Efforts stay out even with the filter off.
- **ADR** — A decision record at a **Site**’s `docs/adr/*.md`. A Map list row. Never Finished; never Archived by the Effort control.
- **Out-of-scope record** — A triage rejection file in a **Site**’s `.out-of-scope/`. A Map list row. Never Finished; never Archived by the Effort control.
  _Avoid_: Out of scope (that is a section on a **Map**)
- **Frontier** — Open, unblocked, unclaimed **Tickets**. The Reader does not claim; it only marks the frontier on the **Map list**.
- **Map list** — The Reader sidebar, with two tabs. **Context** lists language documents, then **ADRs**, then **Out-of-scope records**, across **Sites**. **Tickets** is the Effort outline grouped by Site: **Map** if present, **Spec** if present, and **Tickets** by title indented by `Blocked by:` depth. Frontier marked; resolved dim unless the **Unresolved filter** hides them. Not a filesystem tree. No Files / Decisions toggle. Locked in [docs/adr/0005-map-list-replaces-files-view.md](docs/adr/0005-map-list-replaces-files-view.md), amended by [ADR 0008](docs/adr/0008-map-list-named-holes-for-adrs-and-out-of-scope.md) and [ADR 0010](docs/adr/0010-marker-walk-finds-sites.md).
- **Context tab** — The **Map list** tab for language documents, **ADRs**, and **Out-of-scope records**. Not remaining work.
  _Avoid_: Language tab, Issues tab
- **Decisions view** — Retired name for a Files / Decisions toggle. The ticket outline is the **Map list**.
- **Files view** — Retired. Was the filesystem tree of `.scratch/` filenames.
- **Skip prompt** — Clipboard text from selected **Tickets**. Tells a grilling session to skip the interview on those Tickets, pick the agent’s recommended answer for each, and mark them resolved. Checking a Ticket is the go for that recommendation. Selection is exact: dependents are not included. The Reader only copies; the pasted session writes the **Project**. Locked in [docs/adr/0004-decisions-view-and-skip-prompt.md](docs/adr/0004-decisions-view-and-skip-prompt.md).
- **Take prompt** — Clipboard text for one previewed remaining-work **Spec** (no Tickets yet) or one **Frontier** Ticket. Claimed Tickets stay on the Map list as claimed and are not takeable, so a second session does not duplicate work. First lines are the skill commands for that row’s flow. Tells the pasted session to take only this unit and, for a Ticket, mark it resolved. A Spec Take never sets Spec status to `resolved`. `/wayfinder` prefixes only wayfinder-typed Tickets (`research` / `prototype` / `grilling` / `task`); a Spec with no Tickets is `/to-tickets`; any other Ticket is `/implement`. The Reader only copies; the pasted session writes the **Project**. Locked in [docs/adr/0009-take-prompt.md](docs/adr/0009-take-prompt.md).
  _Avoid_: artifact prompt, copy prompt, work prompt
- **Term** — A glossary entry from a language document’s `## Language` or `## Glossary` section (`**Name**:` or `- **Name** —`), not free bold.
- **Term hint** — Hover definition of a **Term** (and `_Avoid_` aliases pointing at the canonical Term) on the GFM preview, from that preview’s **Site lineage** only. Closest Site that defines a phrase wins; an inherited hint names the ancestor Site; when two glossary phrases overlap, the longer one is the hint. Locked in [ADR 0006](docs/adr/0006-term-hints-from-language-files.md) and [ADR 0016](docs/adr/0016-term-hints-use-site-lineage.md).
- **Paste preview** — Ephemeral GFM the visitor pastes. Rendered in the preview pane with **Term hints** from the current **Map list** selection’s **Site lineage** (none this Load → root Site only). Never a Project-wide merge. Not a **Map list** row. Session memory only; never written to the Project. Cleared on Load. Hosted and **Always-on**.
  _Avoid_: transcript (that is one source of the paste), highlight (that is **Term hints**), scratch pad
- **Always-on** — A permanent version of the **Reader**: `launchd` user agent plus bookmark at `http://127.0.0.1:5420`, Hono **Project path** Load and **Archive**. Not the public origin and not a leftover of it; do not use this word for GitHub Pages staying up. Locked in [ADR 0001](docs/adr/0001-launchd-user-agent-for-always-on.md), [ADR 0014](docs/adr/0014-always-on-stays-a-version.md), and [ADR 0015](docs/adr/0015-always-on-hono-path-load-and-archive.md).
- **Readable tree** — Retired as UI (that was Files view). The Reader hunts **Sites** by marker (`CONTEXT.md`, `.scratch/`) inside the **Project**; it does not read source, `.git`, `node_modules`, or secrets. It may show **Map list** rows, each Site’s in-`.scratch/` preview-link targets (research, prototypes), language files, **ADRs**, and **Out-of-scope records**. Locked in [ADR 0002](docs/adr/0002-readable-tree-is-scratch-only.md), amended by [ADR 0005](docs/adr/0005-map-list-replaces-files-view.md), [ADR 0006](docs/adr/0006-term-hints-from-language-files.md), [ADR 0008](docs/adr/0008-map-list-named-holes-for-adrs-and-out-of-scope.md), [ADR 0010](docs/adr/0010-marker-walk-finds-sites.md), [ADR 0012](docs/adr/0012-file-system-access-load.md), and [ADR 0018](docs/adr/0018-hosted-directory-snapshot-fallback.md).
- **Stack** — Hosted origin: static HTML/JS at a public URL. GFM preview in the page. No Electron, no Vite/Next at runtime. Hono is not the hosted process. **Always-on** is Hono on `127.0.0.1:5420` serving that same `public/` plus the project APIs. Locked in [ADR 0003](docs/adr/0003-hono-static-page-for-the-reader.md), [ADR 0012](docs/adr/0012-file-system-access-load.md), [ADR 0015](docs/adr/0015-always-on-hono-path-load-and-archive.md), and [ADR 0018](docs/adr/0018-hosted-directory-snapshot-fallback.md).
- **Look** — Dark reading desk: laid paper GFM in Literata (`#1c1917` paper, `#e4ddd2` ink), stone **Map list**, navy Load (`#1e3a5f`). Chrome is Source Sans 3. Fonts self-hosted. On-dark strokes, links, Skip/Take, Spec/Frontier marks, and active tabs use Accent Ink (`#7a9cc4`); Load fill stays Chart Navy. **Term hints** are a dotted underline in existing ink; hover is a titled paper slip that fades long definitions. Always dark; no selector. Locked in [What does the dark reading desk look like](.scratch/dark-look/issues/01-what-does-the-dark-reading-desk-look-like.md) and [Ship the dark Look in the Reader](.scratch/dark-look/issues/02-ship-the-dark-look-in-the-reader.md).
