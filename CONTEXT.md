# CONTEXT

Local viewer for Wayfinder maps on disk.

## Glossary

- **Reader** — This product: a local JavaScript web app, kept available on port 5420, that shows Wayfinder maps from a chosen **Project**. The sidebar is the **Map list**; the pane is GFM preview with **Term hints**. The Reader does not edit, claim, or resolve tickets. It may **Archive** a **Finished** Effort after confirm. Never as a side effect of Load.
- **Project** — A folder on the filesystem the user selects. It may contain one or more Wayfinder **Efforts**.
- **Project path** — The absolute POSIX path of that folder. The **Reader** stores this string on the server (type/paste + recents). Browser folder pickers do not produce it.
- **Effort** — A `.scratch/<slug>/` directory the **Map list** can show, except **Archive**. It may have a **Map**, a **Spec**, **Tickets**, or any combination. A Map is optional.
  _Avoid_: folder (when you mean this unit)
- **Map** — The index issue for an Effort (`map.md` locally): Destination, Notes, Decisions so far, fog, out of scope. It lists decisions; it does not restated their detail. Optional; an Effort can be Spec-only or Ticket-only.
- **Ticket** — A child issue in an Effort (`issues/NN-*.md`). One decision, investigation, prototype, unblocker task, or implementation slice. Not required to sit under a Map.
- **Spec** — The buildable plan `/to-spec` publishes as `spec.md` in an Effort. `Status: ready-for-agent` means fully specified and grabable (`/implement` or `/to-tickets`), not done. An Effort with a Spec and no Map is Spec-only: that is remaining work.
- **Finished** — An Effort with at least one **Ticket**, every Ticket `Status: resolved` (that string only). Spec, research, prototypes, and fog do not vote. `map.md` is not required. Spec-only with zero Tickets is not Finished.
- **Archive** — `.scratch/.archive/<slug>/`. Hidden; the Map list skips it. A **Finished** Effort moves here after confirm. Not a hard delete. The Reader has no Archive list and no Restore; recovery is moving the directory back on disk.
- **Unresolved filter** — A **Map list** mode that hides resolved Tickets and **Finished** Efforts. Default on; session only (not stored with the Project path). Language documents, **ADRs**, and **Out-of-scope records** stay. Open Tickets (including claimed and blocked) stay. A control shows the full live list. Archived Efforts stay out even with the filter off.
- **ADR** — A decision record at `docs/adr/*.md` (and, when a CONTEXT-MAP exists, a mapped context’s `docs/adr/` still inside the Project). A Map list row. Never Finished; never Archived by the Effort control.
- **Out-of-scope record** — A triage rejection file in `.out-of-scope/`. A Map list row. Never Finished; never Archived by the Effort control.
  _Avoid_: Out of scope (that is a section on a **Map**)
- **Frontier** — Open, unblocked, unclaimed **Tickets**. The Reader does not claim; it only marks the frontier on the **Map list**.
- **Map list** — The Reader sidebar: language documents, **ADRs**, **Out-of-scope records**, then each **Effort** (folder name) with its **Map** if present, **Spec** if present, and **Tickets** by title indented by `Blocked by:` depth. Frontier marked; resolved dim unless the **Unresolved filter** hides them. Not a filesystem tree. No Files / Decisions toggle. Locked in [docs/adr/0005-map-list-replaces-files-view.md](docs/adr/0005-map-list-replaces-files-view.md), amended by [ADR 0008](docs/adr/0008-map-list-named-holes-for-adrs-and-out-of-scope.md).
- **Decisions view** — Retired name for a Files / Decisions toggle. The ticket outline is the **Map list**.
- **Files view** — Retired. Was the filesystem tree of `.scratch/` filenames.
- **Skip prompt** — Clipboard text from selected **Tickets**. Tells a grilling session to skip the interview on those Tickets, pick the agent’s recommended answer for each, and mark them resolved. Checking a Ticket is the go for that recommendation. Selection is exact: dependents are not included. The Reader only copies; the pasted session writes the **Project**. Locked in [docs/adr/0004-decisions-view-and-skip-prompt.md](docs/adr/0004-decisions-view-and-skip-prompt.md).
- **Take prompt** — Clipboard text for one previewed remaining-work **Spec** (no Tickets yet) or one **Frontier** Ticket. Claimed Tickets stay on the Map list as claimed and are not takeable, so a second session does not duplicate work. First lines are the skill commands for that row’s flow. Tells the pasted session to take only this unit and, for a Ticket, mark it resolved. A Spec Take never sets Spec status to `resolved`. `/wayfinder` prefixes only wayfinder-typed Tickets (`research` / `prototype` / `grilling` / `task`); a Spec with no Tickets is `/to-tickets`; any other Ticket is `/implement`. The Reader only copies; the pasted session writes the **Project**. Locked in [docs/adr/0009-take-prompt.md](docs/adr/0009-take-prompt.md).
  _Avoid_: artifact prompt, copy prompt, work prompt
- **Term** — A glossary entry from a language document’s `## Language` or `## Glossary` section (`**Name**:` or `- **Name** —`), not free bold.
- **Term hint** — Hover definition of a **Term** (and `_Avoid_` aliases pointing at the canonical Term) on the GFM preview. When two glossary phrases overlap, the longer one is the hint. Locked in [docs/adr/0006-term-hints-from-language-files.md](docs/adr/0006-term-hints-from-language-files.md).
- **Always-on** — The Reader process stays reachable at `http://127.0.0.1:5420` without a manual start each time the user wants to read a map. Product shape: a `launchd` user agent in `~/Library/LaunchAgents` plus a browser bookmark. A foreground Terminal `node` is not Always-on. Install and ops: [docs/always-on.md](docs/always-on.md). Locked in [Always-on process model for the Reader](.scratch/map-reader/issues/04-always-on-process-model-for-the-reader.md).
- **Readable tree** — Retired as UI (that was Files view). The server still does not walk the rest of the **Project**. It may serve **Map list** rows, in-`.scratch/` preview-link targets (research, prototypes), language files (ADR 0006), **ADRs**, and **Out-of-scope records**. Locked in [What the server may read in a chosen Project](.scratch/map-reader/issues/05-what-the-server-may-read-in-a-chosen-project.md), amended by [ADR 0005](docs/adr/0005-map-list-replaces-files-view.md), [ADR 0006](docs/adr/0006-term-hints-from-language-files.md), and [ADR 0008](docs/adr/0008-map-list-named-holes-for-adrs-and-out-of-scope.md).
- **Stack** — One Node process: Hono serves a static HTML/JS page and GFM preview. No Electron, no Vite/Next at runtime. Locked in [UI stack and shell](.scratch/map-reader/issues/06-ui-stack-and-shell.md).
- **Look** — Reading desk: warm paper GFM in Source Serif 4, stone **Map list**, navy Load. Chrome is Source Sans 3. Fonts self-hosted. Locked in [Visual polish of the Reader](.scratch/map-reader/issues/09-visual-polish-of-the-reader.md).
